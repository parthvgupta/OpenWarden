# OpenWarden v1.0.0

The first public OpenWarden community release provides Bitwarden-compatible clients for Android, macOS, Brave, and Chrome with client-side personal premium functionality enabled.

## Downloads

- `OpenWarden-1.0.0-android.apk` — Android 10+, package `org.openwarden.app`
- `OpenWarden-1.0.0-universal.dmg` — universal Intel and Apple Silicon macOS application
- `OpenWarden-1.0.0-chrome-brave.zip` — Manifest V3 unpacked extension package

## Scope

OpenWarden enables functionality that runs locally in the client. Server-managed features and limits remain controlled by the connected Bitwarden-compatible server and account.

## Verification

All source modifications are published as Git patches against pinned upstream commits. Release checksums are stored in [`SHA256SUMS`](https://github.com/parthvgupta/OpenWarden/blob/v1.0.0/SHA256SUMS), with platform-specific build and verification instructions in the repository.

The macOS application is ad-hoc signed but not Apple-notarized. The Chromium extension must be installed unpacked through Developer mode. These v1.0.0 binaries were built locally from the published patch set; deterministic byte-for-byte builds are not yet claimed.
